# v2.5.0-beta.1

Beta release for **Boomy** show-floor demos plus audio/SLAM dashboard work.

## Highlights

### Boomy demos
- **`yahboom_demo`**: floor chalk art (`draw`: smiley, heart, boomy_b) and social **talkbot** ("Hi, I am Boomy. Who are you?")
- REST: `POST /api/v1/demo/draw`, `POST /api/v1/demo/talkbot`, status/stop endpoints
- speech-mcp TTS when reachable; espeak-ng on Pi fallback
- Mission hooks: `boomy_draw`, `boomy_talkbot`

### Dashboard
- **Audio soundboard** (`/audio`): built-in effects, upload/play/store, fleet audio cross-connect
- **SLAM map** (`/slam`) + YDLIDAR checklist
- D435 / RPLidar S2 mesh assets

### Voice stack
- USB audio via `plughw:2,0`, `/dev/myspeech`, improved espeak routing

## Install

```powershell
git clone https://github.com/sandraschi/yahboom-mcp
cd yahboom-mcp
git checkout v2.5.0-beta.1
uv sync --extra dev
.\start.ps1
```

## Quick demo (CI-safe)

```powershell
$env:YAHBOOM_DEMO_FAST='1'
uv run pytest tests/unit/test_boomy_demos.py -q
```

## Pair with vla-mcp

Use **vla-mcp v0.3.1-beta.1** `vla_pipeline(live=True, boomy_demo='talkbot')` for closed-loop ingest.
